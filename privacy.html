隱私權政策

最後更新：2026-10-19

本政策說明 MorningBriefBot 如何處理 Google 日曆資料及產生的晨報。本工具供超市內部使用。

讀取的資料與用途

經帳號持有人授權後，MorningBriefBot 透過 Google 桌面應用程式 OAuth，以 calendar.readonly 唯讀權限取得指定日曆的活動資訊，用於產生晨報中的活動預告。

晨報整理使用活動標題（summary）、開始時間（start）及結束時間（end）。Google Calendar API 預設回傳的活動物件可能包含其他欄位，因此 API 取得的資料不應理解為僅限上述三個欄位。

活動預告會與日期、天氣資訊整合為晨報。此唯讀權限不會用於新增、修改或刪除日曆活動。

儲存與傳送

Google 授權憑證與整理後的快取儲存在本機。晨報文字及狀態資訊會透過 HTTPS 傳送至 QueryGateway 雲端服務，再供小蔬寶 LINE 在相關對話或群組中回覆查詢。

晨報內含的日曆活動資訊會隨晨報傳送，並可由該 LINE 對話或群組中的接收者閱讀。

保留與刪除

本機最新快取及雲端最新晨報會在下次成功更新時覆寫。目前沒有適用於所有資料副本的統一自動刪除期限。

快取可在 72 小時內作為備援使用；72 小時是備援使用期限，不代表資料會在期限到達後自動刪除。

平台紀錄、備份，以及已送出的 LINE 訊息可能另有留存，不會因最新快取或晨報更新而一併刪除。

如需刪除資料，請聯絡管理者，確認可處理的資料副本與刪除範圍。

撤銷 Google 授權

帳號持有人可在 Google 帳戶設定中撤銷 MorningBriefBot 的存取權限。撤銷後，程式無法再透過該授權進行新的日曆存取；撤銷授權不會自動刪除先前產生、快取或傳送的內容。
